# Object.hasOwn Polyfill

A side-effect-free polyfill/replacement for `Object.hasOwn` that supports all browsers.

## Installation

```bash
npm install @alwatr/has-own
```

```bash
yarn add @alwatr/polyfill-has-own
```

## Usage

```ts
import {hasOwn} from '@alwatr/has-own';

const obj = {foo: 'bar'};
hasOwn('foo'); // true
```
