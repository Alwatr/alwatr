# Alwatr Bind

A high-performance and lightweight binding utility for unidirectional data flow and reactive DOM/context interactions.

## Installation

```bash
# Using npm
npm i @alwatr/bind

# Using yarn
yarn add @alwatr/bind

# Using pnpm
pnpm add @alwatr/bind
```
